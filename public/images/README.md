# Panduan Penempatan Foto Profil

Silakan taruh foto profil kamu di dalam folder ini:
`public/images/profile.jpg` (atau `public/images/profile.png`)

### Spesifikasi yang Disarankan:
- **Nama file**: `profile.jpg`
- **Rasio**: 1:1 (Kotak/Persegi, misalnya 600x600 px atau 800x800 px)
- **Format**: JPG, PNG, atau WEBP
- **Keterangan**: Website telah dilengkapi fallback otomatis. Jika foto belum dimasukkan atau gagal dimuat, web akan secara elegan menampilkan avatar monogram "DA" Neo-Grotesque tanpa merusak tampilan.
